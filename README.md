# みどりの記録

植物の日々の記録を管理する、ブラウザーとAndroid向けのPWAです。

## 公開ページ

GitHub Pagesで公開されます。

## 主な機能

- 水やり・肥料・観察記録
- 植物カタログと検索
- オフライン利用
- GeminiまたはChatGPT連携（任意）

## ローカルで開く

`index.html` をブラウザーで開くか、ローカルHTTPサーバーで配信します。

## AI連携

APIキーはブラウザーやアプリに保存せず、[セットアップガイド](GEMINI-AI-SETUP.html)に従ってCloudflare WorkerのSecretへ登録してください。
