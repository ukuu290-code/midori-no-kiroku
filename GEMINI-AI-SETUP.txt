AI 植物相談のセットアップ（Gemini / ChatGPT）

このアプリは Gemini API または ChatGPT（OpenAI API）を Cloudflare Workers 経由で利用できます。
API キーは Cloudflare Worker の Secret に保存し、Web アプリや APK には入れません。
詳しい接続手順と公式料金ページへのリンクは GEMINI-AI-SETUP.html を確認してください。

天気を使った水やりプラン:
- 通知設定で通知を許可し、「位置情報を許可して天気を設定」を押して天気を取得します。植物カードの「屋外で管理」を選ぶと、雨予報も確認日に反映します。
- 位置座標は約1km単位に丸めて端末に保存し、天気取得時にOpen-Meteoへ送信します。無料APIは非営利用途向けです。位置情報を削除すると季節ごとの目安に戻ります。
- 雨予報は植物ごとに「屋外で管理」を指定した場合だけ反映します。土の乾きは端末から分からないため、通知後に土を確認してください。水やりを自動で実行する機能ではありません。
- 通知設定で「アプリを開いたときに天気を自動更新」をオンにすると、起動時やアプリに戻ったときに確認・更新します。通信量を抑えるため、更新は最大12時間に1回です。「天気を今すぐ更新」で手動更新、「現在地を取り直す」で位置を再設定できます。
- 通知時刻は「おすすめ時刻に自動調整」または手動から選べます。自動は向こう3日間の最高気温をもとに、30℃以上は7時、25℃以上は8時、通常は9時、寒い冬（10℃未満）は10時ごろに土の確認を通知します。予報が古い場合は季節の目安（夏8時、冬10時、その他9時）を使い、天気更新時に見直します。
- 図鑑にない植物は、AI接続なしでも無料のWikipedia検索で植物情報を調べて登録できます。図鑑にある植物は登録済みの育成情報、図鑑にない植物は記事概要と一般的な仮の育成目安でプランを作ります。植物名をWikipediaへ送信します。出典・内容を確認して「植物を登録」を押すと保存されます。
- 登録後は季節ごとの目安を基本に、天気設定があれば予報と過去30日分の蒸発散量で確認日を調整します。屋外設定では雨予報も反映します。天気を更新すると全植物のプランを再計算します。土の湿り具合は分からないので、通知後に土を確認してください。
- AI接続と外部送信への同意が有効な場合は、ボタンからAIのWeb検索を使います。この場合、植物名が選択中のAIサービスに送られ、料金が発生する場合があります。
- Android APKは端末内の通知予定により、アプリ終了後も通知できます。Web版はアプリを開いている間だけ通知します。
- 天気データ: Open-Meteo (CC BY 4.0)。https://open-meteo.com/en/terms

Web検索:
- AI接続がなくても、相談画面で検索をオンにするとAIを使わないWeb全体の検索リンクを表示します。植物を選ぶと、その植物名でWikipediaも検索して記事概要と出典を表示します。選んだ植物名はWikipediaへ送信され、質問はDuckDuckGoの検索リンクに含まれます（リンクを開くとDuckDuckGoへ送信）。
- AI接続を設定すると、同じ検索チェックで選択したAIのWeb検索を使って回答できます。検索時は回答の下に出典リンクを表示します。
- Web検索を使うと質問や会話の一部が選択したAIサービスの検索機能に送信され、別途料金が発生する場合があります。無料とは限りません。
- 検索しない場合はチェックを外します。公式料金・無料枠は必ず利用前に確認してください。

追加された記録・確認機能:
- 今日のお世話には、確認日が来た植物だけが表示されます。水をあげる前に土の状態を確認してください。
- 植物カードでは、育成プランの理由と情報の出どころ（図鑑、Wikipedia記事、一般的な仮目安など）を確認できます。天気は土の湿り具合を測定しません。
- 植物ごとの日当たり・置き場所メモは、植物カードから記録できます。環境メモは相談の参考情報で、現在の水やり日数計算には使いません。
- 成長記録には写真を添付できます。写真は長辺1280px以内に縮小して、この端末のブラウザー内に保存されます。別端末には同期されません。
- 状態チェックでは葉の黄ばみ、害虫、斑点、土の過湿などから確認手順を案内します。原因を診断する機能ではありません。
- 通知設定の「夜間（21:00〜翌7:00）は通知しない」を有効にすると、その時間帯を避けて通知します。通知は対象植物をまとめて知らせます。
- 直近の登録・編集・記録・削除は、画面の「元に戻す」から約10秒以内に取り消せます。

注意
- Gemini 無料枠の相談内容は Google のサービス改善に使われる場合があります。個人情報や秘密は入力しないでください。
- OpenAI API は ChatGPT のWeb/アプリ契約とは別サービスです。API 利用に無料枠があるとは限らず、利用料金が発生する場合があります。OpenAI の料金と利用状況を確認し、課金上限を設定してください。
- 各サービスのデータ取扱い、モデル、利用上限、料金、提供条件は変更されることがあります。個人情報や秘密は入力しないでください。
- AI Studio で有料プランに変更したり、課金情報を登録したりしないでください。無料枠外の利用は料金がかかる場合があります。
- Cloudflare と Google の無料枠には利用条件があります。公開アプリで不特定多数に配布する用途には、この簡易セットアップを使わないでください。
- API キーをアプリ、HTML、Worker のコード、GitHub などに貼らないでください。キーは必ず Worker の Secret に登録します。
- Worker URL はパスワードではありません。URL を知る人が無料利用枠を消費する可能性があります。ALLOWED_ORIGINS はブラウザー向けの制限で、API 認証ではありません。URL を公開アプリやSNSに載せないでください。
- Worker は Gemini では gemini-3.5-flash-lite、OpenAI では gpt-4o-mini を使います。モデル名や利用条件は変更される場合があります。

1. 利用するサービスの API キーを作る
   1. https://aistudio.google.com/api-keys を開き、Google アカウントでログインします。
      Gemini を使う場合は API キーを作成します。
   2. ChatGPT を使う場合は https://platform.openai.com/api-keys で OpenAI API キーを作成します。ChatGPT のログイン用パスワードやChatGPT契約情報ではありません。
   3. キーをこのアプリには入力しません。次の手順で Cloudflare に登録します。

2. Cloudflare Worker を作る、または更新する
   1. https://dash.cloudflare.com/ を開き、Cloudflare アカウントを作成またはログインします。
   2. Workers & Pages から Worker を作成するか、前に作成した Worker を開きます。
   3. プロジェクト内の cloudflare/worker.js の内容で Worker のコードを置き換え、保存・デプロイします。
   4. Worker の Settings > Variables and Secrets で次を設定します。
      - Gemini を使う場合: Secret `GEMINI_API_KEY` = Gemini API キー
      - ChatGPT を使う場合: Secret `OPENAI_API_KEY` = OpenAI API キー
      - Text variable: ALLOWED_ORIGINS = アプリを使うページの Origin
   5. Android APK では Origin に https://appassets.androidplatform.net を含めます。
      Web 版も使う場合は、公開先の Origin もカンマ区切りで追加します。
      例: https://appassets.androidplatform.net,https://example.pages.dev
      Origin は https:// とホスト名だけです。末尾の / やページのパスは付けません。
   6. Worker を再デプロイし、表示された workers.dev URL を控えます。

3. アプリから接続する
   1. アプリを HTTPS の Web サイトか Android APK で開きます。file:// で開いたページは接続できません。
   2. 「植物のこと、相談してみよう」欄の「AI 接続設定」を開き、Gemini または ChatGPT（OpenAI API）を選びます。
   3. Worker の https://…workers.dev URL を入力し、選んだサービスへのデータ送信に同意して保存します。
   4. 植物を選んで相談します。サービスとURLの設定はその端末に保存され、次回も使えます。あとから同じ設定画面でサービスを切り替えられます。切替時は新しい送信先への同意を再度確認してください。

4. 後から接続先や API キーを変更する
   - 接続先はアプリの「AI 接続設定」で変更し、保存します。設定は端末・ブラウザーごとに保存されます。
   - API キーを更新する場合は Cloudflare Worker の Settings > Variables and Secrets で該当 Secret（`GEMINI_API_KEY` または `OPENAI_API_KEY`）を更新します。キーを変更してもアプリ側の設定し直しは不要です。
   - 新しいサービスに切り替える場合は、そのサービスの API キーを Worker Secret に登録してからアプリで選びます。

5. APK を使う場合
   - android/app/src/main/assets/index.html も更新されています。設定を反映した APK は Android Studio で再ビルドしてください。
   - 配布済みの古い APK には変更が入りません。

うまく動かない時
- 選択したサービスの API キーと Worker Secret 名（`GEMINI_API_KEY` / `OPENAI_API_KEY`）を確認します。
- ALLOWED_ORIGINS に利用中の Origin を正確に追加します。Android の場合は https://appassets.androidplatform.net です。
- Worker URL、API の利用上限・料金設定を確認します。
- 接続URLを消して保存するとオフライン相談に戻ります。
